Vision-Language Model (VLM) แบบเปิดสำหรับ OCR ภาษาไทยอ่านหน้าเอกสารได้ถูกต้องเกือบทั้งหน้าแล้ว แต่สระและวรรณยุกต์ของไทยมีขนาดเล็ก และเครื่องหมายเพียงตัวเดียวก็เปลี่ยนความหมายของคำได้ งานนี้จึงถามว่าเครื่องหมายเหล่านี้หายไปที่ใด นอกเหนือจากการนับว่าหายไปเท่าไร เราเสนอคะแนนที่วัดเครื่องหมายโดยไม่สนลำดับการอ่าน หักคะแนนข้อความที่เขียนเกิน และไม่ให้คะแนนกับข้อความที่ซ้ำจากการวนซ้ำ บนชุด calibration ของ ThaiOCRBench โมเดล Typhoon OCR 1.5 (2B) เขียนวรรณยุกต์ผิดเพียง 0.65\% ในตำแหน่งที่อ่านพยัญชนะฐานถูกต้อง และเมื่อได้รับข้อความก่อนหน้าที่ถูกต้อง โมเดลเลือกวรรณยุกต์ถูก 98.8\% แม้ไม่เห็นภาพ ในหกโมเดลแบบเปิด mark ส่วนใหญ่หายเพราะไม่ได้อ่านบรรทัด ไม่ใช่เพราะอ่านผิดตัว โดยการไม่ได้อ่านทำให้เสีย mark มากกว่า 7 ถึง 12 เท่า ในบรรดาวิธี decode ที่ไม่ต้องฝึกโมเดลเพิ่ม การหยุดเมื่อตรวจพบการวนซ้ำเพิ่ม mark F1 ให้ทุกโมเดล คือ 0.8 จุดสำหรับ Typhoon และ 10.8 ถึง 24.4 จุดสำหรับโมเดลที่วนซ้ำบ่อย และแทบไม่เปลี่ยน output ที่จบเองโดยไม่วนซ้ำ ส่วน repetition penalty ทำให้ F1 ของหน้าที่ไม่วนซ้ำลดลง และการหักความรู้ภาษาออกทำให้วรรณยุกต์ที่ถูกอยู่แล้วหายไป \todo{การทดสอบเรื่องภาพกับโมเดลอื่นและการยืนยันบนชุดข้อมูลที่เก็บไว้ (locked split) ยังไม่เสร็จ} ผลทั้งหมดเป็นผลเบื้องต้นจาก benchmark เดียวและชุด calibration และกฎบางข้อถูกกำหนดหลังจากเห็นข้อมูลแล้ว
