Vision-Language Model (VLM) แบบเปิดสำหรับ OCR ภาษาไทยอ่านหน้าเอกสารได้ถูกต้องเกือบทั้งหน้าแล้ว แต่สระและวรรณยุกต์ของไทยมีขนาดเล็ก และเครื่องหมายเพียงตัวเดียวก็เปลี่ยนความหมายของคำได้ งานนี้จึงถามว่าเครื่องหมายเหล่านี้หายไปที่ใด นอกเหนือจากการนับว่าหายไปเท่าไร เราเสนอคะแนนที่วัดเครื่องหมายโดยไม่สนลำดับการอ่าน หักคะแนนข้อความที่เขียนเกิน และไม่ให้คะแนนกับข้อความที่ซ้ำจากการวนซ้ำ บนชุด calibration ของ ThaiOCRBench โมเดล Typhoon OCR 1.5 (2B) เขียนวรรณยุกต์ผิดเพียง 0.65\% ในตำแหน่งที่อ่านพยัญชนะฐานถูกต้อง และเมื่อได้รับข้อความก่อนหน้าที่ถูกต้อง โมเดลเลือกวรรณยุกต์ถูก 98.8\% แม้ไม่เห็นภาพ เครื่องหมายที่หายไปส่วนใหญ่ไม่ได้ถูกอ่านเลย ได้แก่ บรรทัดที่หายไปทั้งบรรทัด ข้อความที่ขาดเป็นช่วง และ output ที่ถูกการวนซ้ำกินไป ในบรรดาวิธี decode ที่ไม่ต้องฝึกโมเดลเพิ่ม การหยุดเมื่อตรวจพบการวนซ้ำไม่เปลี่ยน output ที่ไม่วนซ้ำเลย และเพิ่ม mark F1 ขึ้น 0.8 จุดสำหรับ Typhoon และ 10.8 จุดสำหรับโมเดลไทยขนาด 0.9B ส่วน repetition penalty ทำให้ F1 ของหน้าที่ไม่วนซ้ำลดลง และการหักความรู้ภาษาออกทำให้วรรณยุกต์ที่ถูกอยู่แล้วหายไป \todo{ผลของโมเดลอื่นและการยืนยันบนชุดข้อมูลที่เก็บไว้ (locked split) ยังไม่เสร็จ} ผลทั้งหมดเป็นผลเบื้องต้นจาก benchmark เดียวและชุด calibration และกฎบางข้อถูกกำหนดหลังจากเห็นข้อมูลแล้ว
