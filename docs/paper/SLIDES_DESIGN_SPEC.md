- 16:9, 1920×1080 px (ใน Canva: Presentation 1920×1080)

## 1.3 พื้นหลัง และเลเยอร์ (ให้ดูมีมิติ)

- **พื้นหลังหลัก:** gradient เส้นตรง 160° จาก `paper` (#FFFFFF) ที่ 0% ไปที่ `paper-warm` (#FFF6EC) ที่ 100% สว่างและจางมาก ตัวอักษร ink-900 ต้องมี contrast ≥ 7:1 กับทุกจุดของพื้น
- **เลเยอร์ตกแต่ง 3 ชั้น (ซ้อนกันที่มุม ไม่ทับเนื้อหา):**
  1. ชั้นหลังสุด: วงกลม/โค้งใหญ่ `orange-300` ความโปร่ง 12–18% ล้นออกนอกมุมขวาบน (เส้นผ่านศูนย์กลางราว 900 px)
  2. ชั้นกลาง: วงกลมเล็กกว่า `orange-500` ความโปร่ง 10% ซ้อนทับชั้นหลังคนละตำแหน่ง ชิดมุมซ้ายล่าง (ราว 520 px)
  3. ชั้นหน้า: เส้นโค้งบาง (stroke 3 px) `orange-500` ความโปร่ง 35% พาดผ่านขอบบนหรือขอบล่าง เพื่อให้ลึก
- สลับตำแหน่งชั้นตกแต่ง (มุมขวาบน / ซ้ายล่าง / ขวาล่าง) ตามกลุ่มหัวข้อ 7 ส่วน เพื่อบอกส่วนที่กำลังพูด ใช้ตำแหน่งเดียวกันทั้งส่วน
- ห้ามวางเลเยอร์ตกแต่งทับกราฟ ตาราง หรือการ์ดตัวเลข กราฟวางบนการ์ดพื้นขาวทึบเสมอ
- **การ์ด:** พื้น `#FFFFFF` ทึบ มุมโค้ง 24 px เงานุ่ม (offset y 10, blur 32, `ink-900` ความโปร่ง 10%) ขอบบาง 1.5 px `orange-100`
- **แถบหัวข้อ:** แท่งตั้งหนา 10 px สี gradient `orange-300` → `orange-500` ชิดซ้ายของหัวข้อ

## 1.4 ตัวอักษร

- **หัวข้อ:** `Prompt` น้ำหนัก SemiBold (600) 54–64 pt · **gradient บนตัวอักษรหัวข้อ** จาก `orange-500` (#E8690B) ซ้าย ไป `amber-600` (#B8480A) ขวา มุม 90° (ใช้เฉพาะหัวข้อหน้า ไม่ใช้กับตัวเลขหรือเนื้อหา)
- **เนื้อหา:** `IBM Plex Sans Thai` หรือ `Sarabun` น้ำหนัก 400/500 28–36 pt สี `ink-900`
- **ตัวเลขในการ์ด:** `Prompt` Bold 120–160 pt สีทึบตามความหมาย (ห้ามใช้ gradient ที่ตัวเลข)
- **ป้ายเล็ก/แหล่งที่มา:** 22 pt `ink-600`
- **ศัพท์อังกฤษ/ชื่อโมเดล/ชื่อเมตริก** (mark F1, Typhoon, Pathumma, S1, R1, greedy, forced choice) ใช้ฟอนต์เดียวกับเนื้อหา ไม่เปลี่ยนฟอนต์กลางประโยค
- **เนื้อหาไทยมีวรรณยุกต์และสระบนล่าง (เรื่องของงานนี้เอง):** line-height อย่างน้อย **1.35×** ในหัวข้อ และ **1.45×** ในเนื้อหา และตรวจด้วยตาว่า ่ ้ ๊ ๋ ิ ี ึ ื ุ ู ไม่ถูกตัด ไม่ทับบรรทัดบน หลังใส่ gradient ที่ตัวอักษร หากเอฟเฟกต์ gradient ทำให้ mark หาย ให้ลดเป็นสีทึบ `orange-500`

## 1.5 ส่วนประกอบซ้ำ

- **ตราสถาบัน:** มุมบนซ้ายของหน้าปก และมุมล่างซ้ายหน้าอื่นขนาดเล็ก (ความสูง 56 px) ใช้ไฟล์ตราที่เจ้าของงานให้ ห้ามวาดเอง
- **เลขหน้า:** มุมล่างขวา 22 pt `ink-600` รูปแบบ `n / 27`
- **ป้ายสถานะผล (มุมล่าง กลางหรือซ้ายถัดจากตรา) ตามที่ `SLIDES_CONTENT.md` กำหนด:**
  - หน้าที่เป็นผลบน calibration: "ผลเบื้องต้น · ชุด calibration (ใช้ออกแบบวิธี)"
  - หน้าที่เป็นผลบน locked: "ผลเบื้องต้น · ชุด locked อ่านครั้งเดียว · ไม่ใช่หลักฐานผ่าน gate"
  - แคปซูลพื้น `orange-100` ตัวอักษร `amber-600` 22 pt
- **ป้ายติดตัวเลข Typhoon และ Pathumma** (Typhoon มาจากกลุ่มที่ทำ benchmark, Pathumma ไม่ระบุข้อมูลฝึก) ใต้ตัวเลขของสองโมเดลนี้ทุกที่

## สไลด์ 2: mark ตัวเล็กตัวเดียว เปลี่ยนความหมายของคำได้

- **เลย์เอาต์:** B การ์ดกลาง: การ์ด ข่าว / ข้าว ใหญ่ตรงกลาง สามบรรทัดอยู่ใต้การ์ด
- **ข้อความบนสไลด์ (ใส่ตามนี้):**
    - **ข่าว** (news) ≠ **ข้าว** (rice) ต่างกันที่ mark ตัวเดียว
    - ตัวชี้วัด OCR ไทยที่ใช้อยู่ (n-gram, edit distance, CER) บอกไม่ได้ว่า mark เป็นปัญหาหรือเปล่า
    - และลงโทษโมเดลที่อ่านคอลัมน์สลับลำดับด้วย
- **ภาพ/องค์ประกอบ:** การ์ดตัวอักษร ข่าว / ข้าว ขนาดใหญ่ตรงกลาง ใต้การ์ดมีสามบรรทัดข้างบน (โปรแกรมสไลด์)
- **Speaker notes (ใส่ใน notes ไม่ขึ้นสไลด์):** "ลองดูคำว่า ข่าว กับ ข้าว ต่างกันที่ mark ตัวเดียว คนอ่านเห็นทันทีว่าผิด แต่ตัวชี้วัดที่ใช้กันอยู่เห็นเป็นตัวอักษรหนึ่งตัวจากหลายร้อยตัว และยังหักคะแนนเมื่อโมเดลอ่านคอลัมน์สลับลำดับด้วย"

## สไลด์ 3: เมื่อ mark ผิด มีสามคำอธิบาย และต้องแก้ต่างกัน

- **เลย์เอาต์:** C ตาราง: ตาราง 3 แถว แถวที่สามเน้นด้วยแถบส้มโปร่ง บรรทัดคำถามใต้ตาราง
- **ข้อความบนสไลด์ (ใส่ตามนี้):**
  | คำอธิบาย                                                   | ถ้าจริง ควรแก้ด้วย                       |
  | ---------------------------------------------------------- | ---------------------------------------- |
  | หลักฐานในภาพของ mark ขนาดเล็กอ่อน                          | อ่านซ้ำ หรือขยายภาพ                      |
  | ความรู้ภาษาของโมเดลทับหลักฐานในภาพ                         | หักความรู้ภาษาออก (contrastive decoding) |
  | mark **ไม่ปรากฏใน output เลย** (ข้ามบรรทัด หาไม่เจอ วนซ้ำ) | แก้วิธี decode หรือการหาตำแหน่งข้อความ   |
- **ภาพ/องค์ประกอบ:** ตาราง 3 แถว แถวที่สามเน้นด้วยสีส้มเหลืองโปร่ง ใต้ตารางมีบรรทัดเดียว: "งานนี้ถามว่า: ข้อไหนเกิดบ่อยที่สุด"

- **Speaker notes (ใส่ใน notes ไม่ขึ้นสไลด์):** "ถ้า mark ผิด อธิบายได้สามทาง ภาพอาจเล็กและอ่อนจนอ่านไม่ออก ความรู้ภาษาอาจทับสิ่งที่เห็น หรือ mark ไม่ถูกเขียนออกมาเลย แต่ละทางแก้ไม่เหมือนกัน เราจึงต้องรู้ก่อนว่าข้อไหนเกิดบ่อยที่สุด งานนี้ทำสามอย่าง คือคะแนน mark ที่ไม่สนลำดับ วัดว่า mark หายที่ไหน และประเมินวิธี decode ที่ไม่ต้อง train เพิ่ม"

## สไลด์ 6: คะแนน mark ไม่ลงโทษลำดับการอ่าน
