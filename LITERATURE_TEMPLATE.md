# Literature Evidence Matrix

> Use this as an evidence matrix, not a paper dump. Every paper added must state both what it establishes and what it does **not** establish for this project.

## Rules

- Prefer primary papers and official code repositories.
- Record the date on which rapidly changing 2026 literature was checked.
- Do not infer implementation compatibility from a paper title or abstract.
- Verify compression location from paper/code before categorizing it.
- Do not write "no prior work" based only on a small search.
